# Interactive miniature wedding setting

> Previous exploration. The live studio now uses the outdoor nikkah garden in `art-direction/garden/`; these stage sources are retained for provenance and are not served to visitors.

The built-in `image_gen` tool created a romantic base set and two floral edits. The supplied standing moodboard was the base image's **style reference**; the romantic source became the **edit target** for the traditional and sculptural versions. All calls used `transparent_background: false`.

`export-studio.mjs` keeps one 1000 × 667 WebP base (approximately 83 KB) and exports feathered left/right floral-region overlays from the edited sources (approximately 65 KB traditional and 56 KB sculptural). The architecture, sofa and stage remain stable beneath these layers. Unlike the bride masters, these floral patches include nearby background pixels and do not claim exact pixel preservation within the feathered regions.

The website's separate SVG material layers tint upholstery, fabric accents and bloom details using multiply blending. Separate opacity layers control candlelight/evening ambience and lantern glow. The three palette, floral and ambience choices compose 27 directions from a small asset set rather than 27 full scene images. All imagery is lazy-loaded and all transitions are disabled for reduced motion. This is an illustrated design study, not a client event.
