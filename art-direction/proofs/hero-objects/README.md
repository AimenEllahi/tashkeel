# Floating object production

These four objects are independently positioned and animated through `lib/hero-assets.ts`:

- Open burgundy velvet ring box with two rings.
- Two interlocked antique-gold rings, separately floating.
- Folded blush silk swatch.
- Matching burgundy silk swatch.

The PNGs in this folder are source drafts created with the built-in image-generation tool. The rings required an on-device Apple Vision foreground mask to remove a brown halo. The WebP exports in `public/assets/images/objects/` were cropped to their visible alpha bounds, padded, and resized with `art-direction/tools/export-cutout.mjs`. Exact prompts are in [`prompts.md`](prompts.md).

The objects are conceptual atelier inspiration, not products for sale or artifacts from a real wedding. Their accessible descriptions live with the asset config. The photographs and invitation artwork from the earlier hero pass remain available for later scenes; the homepage now uses a smaller, more varied selection around the bride.
